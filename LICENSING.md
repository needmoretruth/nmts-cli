only** (AGPL-3.0-only). The full text is in [LICENSE](LICENSE), verbatim and unmodified.

## What the AGPL asks of you

You may run this program for any purpose, read it, change it, and pass it on.

If you pass on a changed version — or let other people use a changed version over a network —
you pass on its source code too, under the same licence.

## Running `nmts` does not put your own program under the AGPL

Calling `nmts` from your own script, agent, or service runs it as a **separate program**. Two
programs that talk to each other through a command line, a pipe, or a socket are separate works;
your code is yours, under whatever licence you like. This is the Free Software Foundation's own
reading of the GPL family, and it is the way this tool is meant to be used.

The AGPL reaches code that is *combined into* one program with this one — a fork of `nmts`, or
software that imports its modules — not code that *invokes* it.

## If the AGPL does not fit

Some organisations cannot take AGPL code into their systems, whatever the shape of the
integration. A separate licence can be arranged.

Write to **nmts@nmts.me**, and say **why a separate licence is needed** — what you want to build,
and which part of the AGPL is in the way. Requests are read and considered on their merits.

Please include enough for the request to be understood on its own. No particular outcome is
promised, and no response time is promised.

## Contributions

**This repository does not merge outside code.** That is deliberate, and the reason is the
paragraph above: a separate licence can only be granted by whoever holds the copyright in all of
the code. Merging a patch would move part of that copyright to its author, and the offer above
would stop being true for the whole program.

Bug reports, questions and ideas are welcome — those cost nothing and change everything.
